# Cover Letter Templates and Tailoring Guide

## Format: Clean Markdown

Cover letters are written as clean, well-structured Markdown documents.

**Output file:** `cover_letters/cover_<company>_<role>.md`

Keep the markdown clean and portable: standard headings, bullet lists, and bold labels only. No HTML, no inline styling - the file should render correctly anywhere and convert cleanly to PDF or DOCX if the user wants to export it later.

## Document Structure

```markdown
# [YOUR_NAME]

[YOUR_EMAIL] | [YOUR_PHONE] | [LinkedIn]([YOUR_LINKEDIN_URL])

[Date]

Dear [Name/Team],

[Opening paragraph - role, connection to background, 2-3 sentences]

[Body paragraph - most relevant experience, leading into the bullet list]

- **[Label]:** [Concrete achievement/skill 1]
- **[Label]:** [Concrete achievement/skill 2]
- **[Label]:** [Concrete achievement/skill 3]

[Connection to company - why this role, why this company specifically]

[Personal fit paragraph - behavioral strengths, team contribution, 2-3 sentences]

I look forward to hearing from you.

Kind regards,

[YOUR_NAME]
```

### Formatting conventions

- One `#` H1 for the candidate name, contact line directly beneath it.
- Date on its own line, then the salutation.
- Body is plain paragraphs separated by blank lines - no headings inside the letter body.
- Closing ("Kind regards,") and printed name at the end, each on its own line.

## Review Loop (MANDATORY)

After writing the cover letter and before presenting to the user, re-read the finished markdown file end-to-end and check:

1. The document renders as clean markdown (no broken lists or stray formatting characters)
2. Body text is within the word budget below (roughly one printed page)
3. The structure matches the template above (salutation, paragraphs, bullets, closing, name)
4. No placeholder tokens remain

## Tailoring Guidelines

### Salutation
- If you know the hiring manager's name: "Dear [First Last],"
- If you know the team: "Dear [Company] hiring team,"
- Generic: "Dear [Company]," (avoid "To whom it may concern")

### Length - Hard 1-Page Limit
- Target: the equivalent of 1 printed page including signature block
- **Word budget: 250-300 words** of body text. This is the safe maximum. 350 words will overflow a printed page.
- **Always count**: opening paragraph + bullet list paragraph + closing paragraph = 3 blocks. Add a 4th only if the others are short.
- When adding company-specific content, trim other content to compensate rather than adding net length

### Bullet Lists
- 3-5 bullets is ideal
- Start each bullet with a bold label or action verb
- Use `**Label:**` for category-style bullets

### Non-English Cover Letters
- Same template structure, just write content in the posting's language
- Adjust date format to local convention
- Adjust closing to local convention (e.g. "Med venlig hilsen," for Danish)

## Checklist Before Finalizing
- [ ] No em-dashes (use commas or periods instead)
- [ ] No cliches or empty filler
- [ ] Every claim backed by specific example
- [ ] Forward-looking framing: focuses on tasks you'll solve, not just past duties
- [ ] Motivation section references this specific company's mission/values
- [ ] Company name and role are correct throughout
- [ ] Date is current
- [ ] Body text within the 250-300 word budget
- [ ] Language matches the job posting language
- [ ] Salutation is appropriate (named person if possible)
- [ ] Headline is engaging and specific, not generic

## Submission Guidelines (Best Practice)
- Submit only the documents the employer requests
- Export as PDF to preserve formatting when the employer expects a formatted document
- Name files clearly: "[Your Name] CV" and "[Your Name] Cover Letter"
- Follow all employer instructions regarding anonymity or specific materials
