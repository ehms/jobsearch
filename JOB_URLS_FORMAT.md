# Job URLs & Cold-Call Targets Format

Update your Obsidian `job-urls.md` file to this format:

```markdown
# Job URLs & Cold-Call Targets

## Job Postings (to parse with /parse)

- https://linkedin.com/jobs/view/123
- https://indeed.ie/jobs/456
- [add URLs here, one per line]

## Cold-Call Targets

- Windmill Lane #coldcall | VFX studio, small team, HBO/Netflix credits
- Brown Bag Films #coldcall | Animation/VFX, hybrid model, Dublin-based  
- Void Interactive #coldcall | Remote games, Unreal-focused, procedural workflows
- Lifesize Plans Ireland #coldcall | LIDAR scanning, 3D visualization (CONTACTED)
- [add companies with #coldcall tag + brief note]
```

## How It Works

**Job Postings:**
- Add direct LinkedIn/Indeed URLs
- Run `/parse` command
- Parser extracts job details automatically

**Cold-Call Targets:**
- Add company name with `#coldcall` tag
- Add brief reason why interested
- When you're ready, say `/cold-call [company]`
- I'll draft personalized outreach email
